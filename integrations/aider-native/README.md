# xnip persistence for Aider scripting

Install the two local Python packages and select `create_xnip_coder()` in the
application that normally calls `Coder.create()`. Aider keeps its format
registry, parsing, matching, confirmation and git policy. xnip persists supplied
text through guarded core transactions. See [the guide](../../docs/aider-native.md)
for the pinned revision, setup, execution and restoration.
