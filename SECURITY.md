# Reporting a security vulnerability

Use GitHub's private vulnerability reporting form to contact the xnip maintainers. [Report a vulnerability](https://github.com/SeaLoong/xnip/security/advisories/new)

Include the affected xnip version or commit, your operating system, what you observed, and the impact. For an integration or benchmark, include the host name and version. Redact credentials and private file contents before submitting the report.
